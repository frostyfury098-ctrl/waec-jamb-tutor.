
# WAEC-JAMB-TUTOR

WAEC-JAMB-TUTOR is a student-focused learning platform designed to help students prepare for WAEC and JAMB through interactive practice and engaging learning activities.

## Features

- WAEC and JAMB study sections
- Practice questions and challenges
- Interactive timed questions
- XP and ranking system
- Daily challenges and activities
- Learning streaks
- Premium learning content
- Student-friendly interface
- Progress-focused learning experience

## Purpose

The goal of WAEC-JAMB-TUTOR is to make exam preparation more interactive, organized, and engaging while giving students a convenient way to practice and monitor their learning progress.

## Technologies

- React
- TypeScript
- Tailwind CSS
- Supabase
- Git/GitHub

## Project Status

Actively developed with new features, improvements, and learning content being added over time.
